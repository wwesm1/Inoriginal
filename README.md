🟢Inoriginal<br/>
Learn English with Movies & Series<br/>
A frontend web project that replicates the Inoriginal user experience — browse movies/series and interactive subtitles — using static HTML, JavaScript, and styles.<br/>

📌 About<br/>
Inoriginal is a web interface originally seen on inoriginal.net for studying English through films and shows with interactive subtitles in Russian, English, or both.<br/>
This project appears to recreate that experience as a static site with:<br/>
HTML pages<br/>
JavaScript frontend behavior<br/>
SCSS/CSS for styling<br/>
Assets and media files<br/>

This repo does not currently include backend logic — it’s purely frontend.<br/>

🚀 Features<br/>

✔ Movies & series browsing layout<br/>
✔ Ratings display<br/>
✔ Subtitles language toggling<br/>
✔ Carousel lists (New, Popular, etc.)<br/>
✔ Styled components (responsive layout)<br/>
✔ No backend — frontend only<br/>
