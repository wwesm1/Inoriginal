🟢Inoriginal
Learn English with Movies & Series
A frontend web project that replicates the Inoriginal user experience — browse movies/series and interactive subtitles — using static HTML, JavaScript, and styles.

📌 About
Inoriginal is a web interface originally seen on inoriginal.net for studying English through films and shows with interactive subtitles in Russian, English, or both.
This project appears to recreate that experience as a static site with:
HTML pages
JavaScript frontend behavior
SCSS/CSS for styling
Assets and media files

This repo does not currently include backend logic — it’s purely frontend.

🚀 Features

✔ Movies & series browsing layout
✔ Ratings display
✔ Subtitles language toggling
✔ Carousel lists (New, Popular, etc.)
✔ Styled components (responsive layout)
✔ No backend — frontend only
